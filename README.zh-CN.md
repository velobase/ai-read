# ByPage · 逐页

**跨越语言，读懂每一页。**

一个本地优先、可自行运行的开源电子书阅读器，围绕多语言阅读和有原文依据的 AI 理解设计。采用 Next.js App Router、TypeScript、Tailwind CSS 和 shadcn/ui，使用 MIT 许可证。

[English](README.md) · [架构说明](docs/architecture.md)

> 当前为 **v0.1.0 alpha**：TypeScript 检查和生产构建已通过；少量本地阅读与 AI 流程的实测见 [验证记录](docs/mobile-verification.md)，不代表所有设备和服务商均已验证。引用存在不代表回答一定正确，请回到原文核对。

## 界面与阅读语言

界面支持 10 种语言：简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、葡萄牙语和阿拉伯语。在「我 → 设置 → 界面语言」切换；登录页和桌面顶部也有语言入口。首次使用时自动识别浏览器语言，菜单只显示具体语言并记住你的选择，并支持日期、数量和阿拉伯语从右到左的界面布局。

翻译与 AI 回答支持选择 **65 种目标语言**，在「阅读语言」或「阅读偏好」中设置。它与界面语言、书籍原文语言独立；切换界面不会改变原文、已有笔记、译文目标或 API Key，也不会发起模型请求。实际翻译能力取决于所连接的模型。

书籍详情可更正原文语言，适用于缺少语言声明的 PDF/TXT 或元数据有误的 EPUB；「按文件默认」可恢复文件声明。原文与目标语言相同时直接阅读，已有正文、笔记和译文仍保留。详见 [原文语言设置](docs/source-language.md)。

## 已实现

- **账号与身份**：Google 登录、PostgreSQL 用户资料、可撤销会话；本机书库按账号区分，游客数据完整保留。配置见 [账号说明](docs/authentication.md)。
- **本地书架与同步**：导入无 DRM 的 EPUB、UTF-8 TXT 和文字版 PDF，自动保存阅读位置；同一账号同步书籍、书架状态、进度、笔记、AI 对话、自动译文和阅读偏好。
- **完整阅读页面**：阅读首页、三列手机书架、书籍详情、分类与书单、搜索、全局笔记和个人资料；桌面与手机分别适配导航和布局。
- **书架管理**：排序、筛选、置顶、阅读状态、分组和可恢复的收起；新导入 EPUB 可保留封面。
- **EPUB 插图**：保留支持的 JPEG/PNG 块级插图，按原位置放在原文或译文段落旁，可点开放大。详见 [插图支持与限制](docs/epub-images.md)。
- **EPUB 脚注与链接**：预览脚注、跳到正文并返回原处；附注独立保存，不改已有段落、笔记和译文。详见 [书内引用](docs/epub-references.md)。
- **多语言阅读**：在「阅读语言」选择原文 / 双语 / 仅译文及目标语言，立即生效并按书记住。先读取已保存译文，缺失的当前段及附近少量段落随阅读自动补齐。双语保留原文，仅译文缺失时显示占位。新用户默认原文。
- **AI 伴读**：解释段落、梳理论证、关联章节；流式回答附段落引用，可点击返回原文。
- **阅读范围**：当前章节、截至最远打开的章节、整本书；长书通过跨语言检索词查找相关原文。
- **摘录与笔记**：先保存在本地，登录后同步，支持导出 Markdown；同时修改的笔记保留冲突副本。
- **阅读界面**：居中书页与外围工具，覆盖式目录、搜索和 AI 面板；手机轻点正文收起工具。字号、字体、行距、页宽 / 边距和昼夜模式可调。
- **自带示例**：原创英文短书及预置中文译文，无需模型即可阅读；不会把示例译文伪装成实时 AI 结果。
- **原版书目推荐**：公开展示五本经济学与商业管理英文书籍的具体版次、ISBN 和官方来源；目前为书目，尚未提供站内全文及译文。详见 [书目与内容状态](docs/recommended-books.md)。

## 本地运行

需要 Node.js 22.15+。

```sh
git clone https://github.com/velobase/ai-read.git
cd ai-read
npm ci
npm run dev
```

打开 **http://127.0.0.1:4173**。Next.js 同时提供阅读界面和 AI API 路由，阅读器在浏览器运行。启动脚本读取环境变量或 `.env` 中的 `PORT`（默认 4173），并关闭 Next.js 遥测。沿用原来的域名和端口即可继续读取已有本地书架。

生产模式（构建产物在 `.next/`）：

```sh
npm run build
npm start
```

默认启动脚本仅监听 `127.0.0.1`，并校验 Host / Origin。已支持真实账号和服务端会话；公共部署的 HTTPS、线上 PG、域名和运行环境需另行准备。请固定使用同一个地址与端口，浏览器按来源分别保存书架。

## 配置 AI

在右侧「阅读伙伴」点击设置图标，填写兼容 Chat Completions 的服务地址、模型 ID 和 API Key。服务需支持流式 SSE 输出，以及非流式问答。登录后，连接配置保存在账号下，API Key 在服务端加密保存；修改服务地址、模型或 Key 后，下一次请求立即使用新配置，无需发布或重启。Key 留空保留已有密钥，更换服务地址时需重新填写或明确移除。未启用账号的本地模式仍只在页面内存保留手动输入的 Key。

未启用账号的本地模式也可以复制 `.env.example` 为 `.env`，配置 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`。修改后重启服务。服务端密钥不会返回浏览器，也不会随用户切换的服务地址转发。

在同一设置页可选择「自然流畅 / 严谨学术 / 贴近原文」，并直接编辑翻译 Prompt（可用中文写术语和示例）。支持 `{{to}}`、`{{from}}` 变量，原文、书名和相邻段落自动提供。保存到账号后无需发布；新设置用于后续缺失段落，已有译文、版本标识和笔记保持不变。

本地 Ollama 可以使用 `http://localhost:11434/v1`，模型名称填写已经安装的模型。项目不附带模型、密钥或 API 额度。

双语和仅译文模式优先使用已保存文字，再自动补齐当前阅读位置及附近少量段落；完成的段落自动保存，阅读空闲时保持位置更新排版。切回原文、离开阅读器或进入后台会停止不再需要的翻译；返回正在阅读的双语或仅译文上下文可从兼容的已保存分块继续。阅读流程不再提供整本准备、暂停任务或切换译本步骤。离线时保留本机译文，持续失败时在缺失内容附近显示重试。费用由已有连接的模型服务收取。详见[随读翻译说明](docs/chapter-translations.md)。

随读翻译不阻塞问答。直接问“这里是什么意思”，AI 会参考当前阅读位置；选中文字后以选中内容优先。长书问答可能增加一次检索词生成请求，回答可随时停止。

## 数据如何保存

原始文件在浏览器解析，不上传原始 EPUB/TXT/PDF 文件。书籍正文、已支持的 EPUB 插图、位置、笔记、译文、对话先保存在 IndexedDB，普通偏好保存在 localStorage。登录后，解析后的正文、封面与已支持的插图、书架状态、位置、笔记、已完成的对话、自动译文和阅读偏好同步到当前部署的 PostgreSQL。游客数据只保存在本机，可在数据页主动复制到账号。字体随项目打包。可选 PostHog 匿名统计需要部署配置，并在「设置 → 诊断与隐私」主动开启，默认关闭。本次会话诊断仅保存在页面内存。服务端日志与指标只记录操作类型、耗时和状态，不记录阅读内容或密钥。详见[可观测性说明](docs/observability.md)。

使用 AI 时，相关原文、所选文字、书名、问题和符合当前范围的近期对话，会经本地代理发给你配置的服务商。上下文仍只有文字：保留插图不会把图片像素发送给模型，也不会翻译图片内的文字。若所选范围很短，可能包含其全部文字；长书则选择部分原文。

清除浏览器网站数据会删除书架。请保留原书，并在「我 → 数据与备份」导出已解析的书籍、封面、已支持的 EPUB 插图、笔记与阅读位置。恢复时保留已有正文和位置，合并缺少的笔记，也可补充兼容的缺失插图。普通备份不含 API Key、AI 对话和译文缓存；[跨端阅读包](docs/mobile.md#move-reading-between-web-and-ios)另可携带本机已保存的译文。两种格式均不含原始 EPUB/TXT/PDF 文件；供原页查看器使用的原 PDF 单独保存在本机，不进入账号同步或导出。登录账号的 AI 连接配置单独保存在 PostgreSQL，密钥加密存储且不会返回浏览器，也不写入浏览器持久化存储或导出文件。界面语言仍保留在当前设备。

同步在本机修改后、回到页面、重新联网及前台定期检查时进行。页面已经打开时，断网仍可继续读本机书籍和做笔记，联网后补传；当前未提供离线启动的 PWA。阅读位置按章节、段落和段内位置保存，百分比按原文字数计算，回读可以下降；“已读完”由用户标记。另一设备更新位置时，当前阅读不会自动跳页，下次打开书使用已保存的位置。旧离线进度遇到版本冲突时保留云端位置，本机旧位置可从数据页导出副本。

同步复用账号数据库，无需 Redis。配置好 `.env` 中的本地数据库后运行 `npm run db:migrate`；完整配置见 [账号说明](docs/authentication.md)。跨设备需访问同一个部署并登录同一账号。

## 首版范围

当前支持重排文字、EPUB 封面和 JPEG/PNG 块级插图。图中的表格和公式可作为原图查看；文字表格、公式和复杂版面不会自动还原。混合在文字中的行内图片、SVG、没有文字锚点的纯图片章节会计入未转换数量，不虚构位置。行内样式仍未保留；脚注与书内链接通过独立引用数据保存。插图单资源最多 4 MiB、每书 12 MiB，单份经过验证的备份或阅读包合计最多 24 MiB 图片字节；JSON 编码后的文件会更大，大书库应分书导出。补图和补充引用不改变段落 ID、文字锚点或译文来源哈希。详见 [EPUB 插图说明](docs/epub-images.md) 与 [书内引用](docs/epub-references.md)。

PDF 使用独立的本地解析组件，支持页码范围、密码、转换预览和原始页码出处；网页读取文字层，iOS 可选本机 OCR 识别扫描页。本机原页查看器保留源文件中的图表和公式，并可返回对应文字章节；原 PDF 不进入同步或阅读包。详见 [PDF 解析说明](docs/pdf-import.md)。不提供 DRM 移除和有声书目录；iOS 支持系统语音朗读。EPUB 需要有效 XHTML，最大 30 MB；提取后单个文字文件最大 4 MB、总文字最大 20 MB，封面最大 2 MB。TXT 需要 UTF-8 编码，按每 60 段拆分阅读小节。

AI 使用有限上下文和关键词检索，不保证查全全书。引用按钮只表示原文被提供给模型，不能证明推断正确。「截至最远章节」按打开章节计，不表示其中每段都已读过；模型自身知识也可能造成剧透。

修改模型或翻译要求只影响后续缺失文字，不替换已保存译文和笔记引用。历史完整译本继续可读；暂不提供手工术语管理或翻译校订。

本轮在用户明确允许少量测试后，只做了少量针对性检查和人工模拟器验证，没有运行完整自动化测试套件。静态检查可运行 `npm run typecheck`，打包可运行 `npm run build`；后续检查仍遵从仓库中的测试偏好。

## 原生 iOS 预览

原生伴读支持本章、已读和全书范围、本机问答历史、原文引用返回及单条 Markdown 导出。原生阅读与网页统一为原文 / 双语 / 仅译文，按书记住语言选择，自动补齐附近缺失段落并保留长段分块。回到仍处于双语或仅译文的阅读页时可继续缺失文字。详见 [伴读](docs/native-assistant.md) 与 [原生随读翻译](docs/native-translation.md)。

`apps/mobile` 使用 Expo / React Native、SQLite、PDFKit / Vision 和 UIKit 翻页，支持本地阅读、笔记、搜索及与 Web 互导阅读包。阅读包可携带已支持的 EPUB 插图和本机已保存的译文，普通网页备份仍保留原有格式。本机模拟器已检查真实 EPUB 的表题与图表同页、查看器完整显示及返回位置；双指缩放与全部版式尚未验证。新增[原生账号连接](docs/mobile-accounts.md)，通过系统浏览器和钥匙串连接现有 Web 账号及其 AI 配置；手机书库仍独立保存在本机，尚未启用云同步，免登录本机服务继续支持。模拟器已到达 Google 登录页并检查两条取消路径，完整登录与账号 AI 尚未实测。见 [启动与架构](docs/mobile.md)、[模拟器实测记录](docs/mobile-verification.md)和[本轮交接说明](docs/iteration-2026-10-23.md)。
