# AI Read

**跨越语言，读懂每一页。**

一个本地优先、可自行运行的开源电子书阅读器，围绕多语言阅读和有原文依据的 AI 理解设计。从零实现，采用 MIT 许可证。

[English](README.md) · [架构说明](docs/architecture.md)

> 当前为 **v0.1.0 alpha**：核心功能已实现，TypeScript 检查和生产构建已通过；阅读交互和真实模型服务尚未做运行验证。引用存在不代表回答一定正确，请回到原文核对。

## 已实现

- **本地书架**：导入无 DRM 的 EPUB、UTF-8 TXT，自动保存阅读位置。
- **双语阅读**：打开即自动翻译屏幕内的内容，提前准备后面三段，完成后缓存；原文 / 双语 / 译文模式自动记住。
- **AI 伴读**：解释段落、梳理论证、关联章节；流式回答附段落引用，可点击返回原文。
- **阅读范围**：当前章节、截至最远打开的章节、整本书；长书通过跨语言检索词查找相关原文。
- **术语一致性**：每本书有独立术语表，提供给翻译和问答。
- **摘录与笔记**：保存在本地，支持导出 Markdown。
- **阅读偏好**：夜间模式、字号调整、章节目录、原文搜索、移动端布局。
- **自带示例**：原创英文短书及预置中文译文，无需模型即可阅读；不会把示例译文伪装成实时 AI 结果。

界面目前为简体中文。翻译和回答可选择简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语或阿拉伯语，实际能力由模型决定。

## 本地运行

需要 Node.js 22.12+。

```sh
git clone https://github.com/velobase/ai-read.git
cd ai-read
npm ci
npm run dev
```

打开 **http://127.0.0.1:4173**。开发模式同时启动阅读界面和本地 AI 代理。

生产模式：

```sh
npm run build
npm start
```

当前版本是个人本地实例，服务仅监听 `127.0.0.1`，并校验 Host / Origin，不提供公共多用户部署能力。请固定使用同一个地址与端口，浏览器按来源分别保存书架。

## 配置 AI

在右侧「阅读伙伴」点击设置图标，填写兼容 Chat Completions 的服务地址、模型 ID 和 API Key。服务需支持流式 SSE 输出，以及非流式问答。API Key 仅保留在当前页面内存，刷新后需重新填写。

也可以复制 `.env.example` 为 `.env`，配置 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`。修改后重启服务。服务端密钥不会返回浏览器，也不会随用户切换的服务地址转发。

本地 Ollama 可以使用 `http://localhost:11434/v1`，模型名称填写已经安装的模型。项目不附带模型、密钥或 API 额度。

双语和译文模式会自动为屏幕内及紧接着的三段未缓存内容逐段请求模型，无需点击翻译。切回原文、切换章节或隐藏页面会中止当前翻译；断网暂停，回到页面或联网后继续。短暂故障最多重试两次，密钥或配置问题会暂停并显示原因。首次生成期间原文仍可阅读，缓存的译文直接显示。实际费用由所用服务决定。

后台翻译不阻塞问答。直接问“这里是什么意思”，AI 会参考当前阅读位置；选中文字后以选中内容优先。长书问答可能增加一次检索词生成请求，回答可随时停止。

## 数据如何保存

原始文件在浏览器解析，不上传整份文件。书籍正文、位置、笔记、译文、对话保存在 IndexedDB，普通偏好保存在 localStorage。字体随项目打包，不含分析统计代码。

使用 AI 时，相关原文、所选文字、书名、问题、术语表和符合当前范围的近期对话，会经本地代理发给你配置的服务商。若所选范围很短，可能包含其全部文字；长书则选择部分原文。

清除浏览器网站数据会删除书架。请保留原书，并导出重要笔记；当前没有云同步和完整书库备份功能。

## 首版范围

当前专注文字阅读，不保留原书图片、复杂排版、公式及脚注跳转。暂不支持 PDF、扫描件、DRM、听书和账号系统。EPUB 需要有效 XHTML，最大 30 MB；提取后单个文字文件最大 4 MB、总文字最大 20 MB。TXT 需要 UTF-8 编码，按每 60 段拆分阅读小节。

AI 使用有限上下文和关键词检索，不保证查全全书。引用按钮只表示原文被提供给模型，不能证明推断正确。「截至最远章节」按打开章节计，不表示其中每段都已读过；模型自身知识也可能造成剧透。

修改模型、服务地址、目标语言或术语表，会使用新的翻译缓存。旧缓存随书籍删除一并移除。

按项目发起人的要求，首版未编写或运行单元测试、集成测试和端到端测试。静态检查可运行 `npm run typecheck`，打包可运行 `npm run build`。
