# Local original and saved-translation search

Web global search and book search can search original text or locally saved translations. The native global search supports a book scope and saved-language choice; native book search uses the language actually displayed by the reader, including a temporarily opened saved translation. Search never prepares a translation, calls a model, or downloads remote translation chapters. Unfinished translation drafts are excluded. Search terms and book text are not telemetry fields.

## Saved text and navigation

The reader's **Contents titles** option is independent of original/saved-translation full-text search. It filters the complete existing directory using the shared normalized title matcher, retains ancestor rows as context and counts only direct matches. It temporarily ignores branch folds; clearing the query restores the session's fold choices. Native contents has the same title behavior, with its existing separate **Search this book** action for full text. **Locate current section** explicitly clears the title query and unfolds its ancestor path. These directory operations do not change the reading position or the stored book contents.

The **PDF original** viewer also provides separate occurrence-by-occurrence text-layer search in the retained local file, on Web and iOS. It highlights original-page geometry rather than reflowed paragraphs. This search neither prepares translations nor alters the book's anchors; explicit **Read this page's text** resolves an existing physical-page chapter. See [PDF search behavior and limits](pdf-import.md#find-in-the-original-pdf) and [the limited manual verification](mobile-verification.md#original-pdf-text-search).

Web scans every locally cached chapter artifact for the selected book/language, including chapters outside the reader's nearby-chapter window. It validates the book, edition, chapter index and original chapter hash. Legacy and portable local translation maps remain supported. Identical paragraph text in the same language is deduplicated across versions, preferring newer saved editions with an ID tie-breaker. Changing the selected edition alone therefore does not reorder pagination. Results retain their exact translation key, UTF-16 match range and whole translated paragraph SHA-256. Opening a result rereads the saved text and verifies the fingerprint and range before applying a translated offset. The URL carries identifiers, a hash and offsets, not the passage text.

Native global and book search read all locally saved exact versions in the requested language, including versions that are not selected for reading. Legacy maps enter the existing lossless migration with their original portable keys. Scanning reads a source-book snapshot without image assets, then at most 32 version records per SQL batch. Each version is checked against the real paragraph, canonical chapter fingerprint and full translated-text SHA-256; invalid saved data reports an error rather than being presented as a valid hit. Matching yields cooperatively and is cancelled when query/scope or the active library lease changes. Results carry their exact saved key and quoted UTF-16 range; opening one rereads that exact version and uses the saved-passage resolver before navigation. It does not change the paragraph's default version. Only versions already on this device are searched; this does not download Web editions or unfinished drafts.

If the target translation no longer matches, navigation explicitly falls back to its original paragraph and avoids applying translated offsets to the original. Saved-version jumps use temporary reading settings; they do not overwrite global preferences or automatically generate missing translation. Closing book search or changing its query/source/page invalidates an in-flight location capture before it can navigate.

## Results and returning

- Each paragraph contributes its first matching occurrence per saved version; this is not an occurrence-by-occurrence concordance. Web original and saved-translation searches now page in batches of 60 in both global and reader search. Offsets count validated, unique matches; one further unique match proves that another page exists. Page labels show the current match range, not a guessed total.
- Native original and translated results page in batches of 60, with one extra match used to detect another page. Books have a stable imported-time/ID order. Original passages follow spine order; saved versions use stable exact-key order, independent of the selected version. The first occurrence per paragraph/version contributes a match, and identical full text for the same paragraph/language is deduplicated across SQL batches before pagination. Different text remains separately searchable and keeps its own exact key. Deep pages rescan prior matches; there is no persisted full-text index or frozen snapshot across pages.
- Web global query, source, language, book scope and result page are represented in the return URL. Changing query or scope resets the first page; switching result tabs preserves it. Book search retains its query, source, language, page and list scroll, and keeps the first pre-search reading position separately from later result jumps. Explicit page changes reset list scroll. Empty or failed deep pages keep previous-page access; global search also offers a first-page return. Pending result activation locks conflicting controls, and leaving or changing search invalidates a delayed jump.
- Native global search retains query, source, language, book and result page while the reader is open. Native book search retains query, source and page and can return to its first pre-search reading position. Native result-list scroll within a page is not retained. Session search state is not persisted across app restarts.
- Native book search keeps that first position separately from the reader's eight-point return history. Following references or other explicit jumps from a result preserves the first origin; opening another result discards the previous result's branch. Returning to the pre-search position restores its earlier return history after verifying its original quote or exact saved translation. **Stay here** clears the generic jump history, leaving the independent search origin available. Pending restoration disables conflicting search controls; closing the sheet invalidates a delayed return.

Web searches traverse books by imported time and ID, then original chapter/paragraph order or saved language/edition/chapter order. Pages rescan earlier matches and do not retain a full-text index or freeze a cross-page snapshot. Importing/removing books or changing saved translations can therefore change subsequent results; refreshing an empty page does not fabricate matches. Only search timing, outcome and result count enter optional diagnostics, never the query or book text.

The native all-version increment was manually sampled in the iPhone 17 Pro simulator using the existing original two-version demo. Read-only SQLite inspection confirmed that the persistent choice remained the newer version and both exact rows remained. Book-search use of the shared scanner, duplicate text across SQL batches, deep pages, cross-book pagination and cancellation received static review but were not manually exercised in this increment. No model request, remote download or automated test was run. See the reading-context record in [mobile verification](mobile-verification.md#reading-context-and-modal-handoffs).

The key local source samples are `结构性改革.epub` and `1366_keynestheoryofemployment.pdf`; the books and private screenshots are not repository fixtures. Native book search also opened an original Chapter 2 match and returned to its first Chapter 1 position. Those earlier checks included type checking, Web production build, iOS JavaScript export, formatting and independent static review.

Each navigation path sampled one result, not every result on its page. Nonzero result-list scroll restoration, concurrent cancellation/navigation, expired-cache fallback, other saved languages and continuous-scroll return were not manually exercised.
