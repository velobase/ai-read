# App 与 Web 界面精简清单

日期：2026-10-23

判断标准：一个实体只有在帮助读内容、做选择、执行操作或识别重要状态时，才需要出现。普通状态不做横幅，已有标签不再配解释，低频操作按需展开。真正的书籍内容、原文证据、错误、权限与数据风险提示保留。

## 全局

| 不必要实体                                     | 处理                                                            |
| ---------------------------------------------- | --------------------------------------------------------------- |
| App 顶部 `Account library · leafread.ai`       | 整条删除。书库类型、切换与同步只在账号页处理。                  |
| Web 导航上的重复导入、语言选择、用户头像入口   | 删除；导入在主页和书架，语言与账号在“我”。                      |
| 空状态的大图标和装饰                           | 删除，保留必要的一句话和可执行操作。                            |
| 无封面书籍的几何形状、假书脊、品牌眉题、假印记 | 删除，保留书名、作者和可辨识的底色；已有真实封面不变。          |
| 无法拖动的原生 Sheet 把手                      | 删除，关闭按钮保留。                                            |
| 设置图标彩色底盘、推广渐变、卡片套卡片         | 删除或改为中性行式布局；选中、警告、主操作仍可辨识。            |
| 单独“设置”中间页                               | 合并进“我”。删除 Web `/me/settings` 和 App 的旧 settings 分支。 |

## 保留边界与验证

- 不删除用户书籍、笔记、译文、书签或账号数据，不改存储与同步协议。
- 不减少服务器原始异常日志，也不把错误/恢复提示当成普通说明删除。
- 保留来源证据、翻译进度、同步授权、注销确认、恢复范围与缺失内容提示。
- 静态复查包含入口可达性、删除路由的残留引用、废弃样式引用和跨端对应关系。
- Web 与 App 类型检查、Web 生产构建及 iOS JavaScript 导出通过。iOS 导出不是原生 Xcode 编译或真机验收。
- 按用户偏好未编写或运行单元、集成或端到端测试，未执行付费模型请求。视觉与实际交互由用户验收。
