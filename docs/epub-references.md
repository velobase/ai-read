# EPUB footnotes and internal links

EPUB references are stored in an optional `Book.references` sidecar. The original chapters, paragraph text and IDs remain the reading source. Adding references does not change translation hashes, note anchors or saved reading positions.

Each link has a stable ID, a kind (`footnote`, `internal` or `backlink`), exact UTF-16 ranges in the original paragraphs, and a target ID. A target either points to existing chapter paragraphs or contains bounded plain-text supplementary content. Notes from non-linear or non-spine EPUB documents stay in this sidecar; importing them does not append chapters or change the old book's content identity.

The parser preserves link ranges alongside its existing whitespace normalization and paragraph splitting. Explicit EPUB/ARIA note semantics identify footnotes. Legacy superscript markers need a matching reverse link from the target to the source before being classified as footnotes. Ordinary local links remain internal links. Remote URLs, executable markup and unsafe archive paths are not followed.

The reading UI previews notes from local text without requesting a model or changing progress. A target with a chapter location can be opened in the original text and returned from. Original ranges are never applied to translated text. Translation-only reading offers a separate original-reference entry point. Supplementary targets have a preview but no invented chapter destination.

Reimport and backup restoration add references only when the book text is identical and the new sidecar preserves all existing links and targets. Conflicting or smaller sidecars cannot remove existing reference data. Web sync includes the bounded sidecar in book metadata, so supplementing references alone does not reupload book text or images. Missing fields from older clients do not delete references. Native SQLite and portable reading packs retain the same format. Account synchronization boundaries are documented separately in [the native sync protocol](native-sync-protocol.md).

Each book allows up to 2,000 links and targets within 512 KiB of serialized reference data. A supplementary target is at most 64 KiB, and a validated backup allows 16 MiB of reference data in total. Oversized or unresolved references are counted as skipped; their visible original text remains readable. The feature does not recreate the publisher's inline styling or execute external links.

## Returning through references and search

Web keeps up to eight in-memory return points for actual reference jumps, including internal links, footnote body visits, saved-bookmark jumps and companion citations. Each point belongs to the current book activation and retains its reading anchor, navigation mode, selection, temporary original view and explicitly revealed saved translation. Opening or closing a footnote preview does not add a return point. A backlink to the most recent departure pops that point, including when the inline marker is below the first visible paragraph on its page; other links create another normal jump. Returning never requests a translation. If the reading language or selected edition changed meanwhile, a translated anchor falls back to the corresponding original paragraph instead of applying an old translated offset to another source.

The first pre-search reading point is separate from this reference stack. Search result visits retain the query, source, language, result page and list scroll. Following a footnote or internal link from a result therefore keeps both the search-results action and the original pre-search position. Returning directly to that position also restores the reference stack that existed before searching. Choosing another result discards the old result's reference branch, while keeping the first pre-search origin. Dismissing the return controls clears both histories. Switching or reactivating a book invalidates them; missing paragraphs are never used as jump targets. These histories are session-only and are not stored in reading packs or restored after a page reload.

The return-chain change passed type checking and independent static review. A later manual check covered search → footnote body → backlink → search results → pre-search position, as recorded below. Nonzero list-scroll restoration, eight successive references, concurrent book changes and changed-version fallback remain static-review coverage.

## Verification

The real EPUB sample retains 47 chapters, 1,640 paragraphs and 271,040 characters with identical paragraph IDs, text and kinds when reference collection is enabled. Its 51 resolved links comprise 43 internal links, four footnotes and four backlinks; the sidecar is 16,462 bytes with zero skipped references. This sample has no non-linear targets or EPUB3 note semantics, so those paths have only been reviewed statically.

On Web, reimport supplemented the existing book and displayed four notes and 43 internal links. Opening the first footnote kept the reader on page 6/9; opening its body moved to page 9/9 and the return control restored page 6/9. On the local iPhone 17 Pro simulator, tapping the original inline marker opened the native note sheet, and its body backlink returned from page 11/11 to page 7/11. A second check used the visible reference-list entry and the dedicated return control, again restoring page 7/11. This caught and fixed a toolbar overlap: when tools are expanded, reference actions now appear above the toolbar; the covered footer has no duplicate active or accessibility controls. Page layout stays unchanged.

Production Web compilation, shared-package and mobile type checking, iOS export and the native Xcode build passed. Live cloud convergence, portable-pack restoration, translation-only reference navigation, RTL, VoiceOver, long-press selection and every turn animation were not manually exercised. The two real reading samples and screenshots remain outside the repository. No automated test suite was added or run for this feature.

In the later Web return-chain check, the real EPUB began at chapter 44 / 92%, page 1/12. Searching `人民币国际化` produced eight results; the first opened paragraph `25.13` in the Hong Kong chapter. Its footnote preview opened the body on page 9/9 while retaining both return controls. The body backlink restored page 6/9. Returning to search retained the same query and page 1 with eight matches; **Return to previous reading position** then restored chapter 44 / 92%, page 1/12. This sampled one original-text reference chain. No book content or annotation was edited. Private evidence: `web-search-footnote-return.png`.
