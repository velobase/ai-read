## 主要功能

- 独立原生 iOS 应用：四个主标签、书架、详情、书内搜索、笔记、阅读进度和 SQLite 本地保存；按 VeloAgent / Velobase Harness 的应用与共享包边界组织。
- 翻页选择仍在：仿真、平移、无动画，以及连续滚动和分章滚动。排版与设置页均可配置。模拟器验证了部分翻页和定位流程，不能据此认定所有手势、设备与动画均已覆盖。
- 独立 PDF 解析组件：Web PDF.js、iOS PDFKit / Vision OCR，统一转换为 `Book → Chapter → Paragraph`；支持预览、页范围、进度和取消。
- AI 伴读可以引用原文、跳回来源并保存想法；iOS 可按章准备翻译，已完成段落逐段保存。原生模型请求使用服务端 Key；Web 自带 Key 仅保存在浏览器内存中。
- 原文与目标语言相同时直接阅读；`zh` 与简体中文视为相同，繁体中文仍单独处理。全局双语偏好和已有译文缓存保持不变。
- 搜索与笔记跳转保留来源和字符偏移；重新分页不再把精确目标覆盖为页面第一段。书内及全局搜索按字符预算让出执行，改善长书操作响应。
- Web 有诊断页、结构化日志、请求关联 ID、受保护的 Prometheus 指标、可配置 OTel 导出和需用户选择开启的 PostHog。原生诊断保存在内存，可主动导出。
